# python/basic/0.0.1

> 独立分支。与 `main`、`python/0.0.1` **没有共同历史**（orphan 根提交），
> 内容互不相干，**永远不会合并到任何其他分支**。

## 这个分支是什么

从零开始的空白工作区，用于独立探索 / 重写，不继承主线的代码、题目与文档。

| | |
| --- | --- |
| 根提交 | `cdc2027`（无父提交） |
| 当前内容 | 仅本说明文件 |
| 与主线历史关系 | 无 |
| CI / 镜像构建 | 不触发（工作流只跑 `main` 与 `python/0.0.1`） |

## 分支约定

1. **不合并**：不向 `main`、`python/0.0.1` 提 PR，也不接受它们合入本分支。
2. **不共享历史**：不对其它分支做 `rebase` / `merge` / `cherry-pick` 引入其提交；
   需要某个文件时手工复制内容，不带提交历史。
3. **允许重写历史**：本分支是实验性质，`git push --force` / `git reset` 随时可用，
   不影响任何其他分支。
4. **不推送标签**：不打 release tag，避免与主线版本号混淆。
5. **名字带年份/序号**：后续迭代另开 `python/basic/0.0.2`，保持每个分支边界清晰。

## 从零起步

工作区是空的（连依赖目录也已清理），需要时按需重建：

```bash
# Python 环境
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# 前端依赖（若用到 Node）
npm install
```
